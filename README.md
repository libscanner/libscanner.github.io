# libscanner.github.io

Mirror for emergency license notices of the libscanner libraries (dmr, dmgen, unir).

`emergency.json` appears here **only** if the libscanner.com license server is down for longer
than the offline period of the licenses. The file is signed by a separate libscanner emergency key;
the libraries verify the signature, never extend a license past its paid term, and accept at most
30 days per notice. Without the file (normal state) this site has nothing to say.

Зеркало аварийных уведомлений лицензий библиотек libscanner (dmr, dmgen, unir).

`emergency.json` появляется здесь **только** если сервер лицензий libscanner.com недоступен дольше
срока работы лицензий без связи. Файл подписан отдельным аварийным ключом libscanner; библиотеки
проверяют подпись, не продлевают лицензию дальше оплаченного срока и принимают не больше 30 дней
за одно уведомление. В обычном состоянии файла здесь нет.
